# Deployment Docker Compose

Small Docker Compose and Dockerfile examples for local experiments with web
servers, Kafka, GitLab, and environment-variable forwarding.

## Contents

- BuildNginx/: an Nginx-based certificate setup experiment.
- GitLab/: a GitLab container configuration example.
- Kafka/ and Kafka - v1.0/: ZooKeeper, Kafka, and control-center examples.
- Sample/: small environment-variable and Dockerfile examples.

The examples are intentionally incomplete and should be reviewed before use.
They reference external images and services; those dependencies are not
included or relicensed by this repository.
